The optional loopback control plane: for **programs on the same machine** (IDE extensions, scripts,
MCP servers, CI steps). Off by default, loopback only, token required, no CORS headers — see
[For local programs](/agent-bridge/en/integrate/local) before you enable it.

Prefer [Local control plane endpoints](/agent-bridge/en/api/control-plane-reference) when you want
to search or deep-link: this viewer renders client-side and is invisible to the site search index.
